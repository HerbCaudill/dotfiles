# DevResults branding

Use this skill as the concise, agent-readable reference for the planned DevResults identity.

Before choosing or applying brand assets, read [references/identity.md](references/identity.md) completely.

## Brand transition

Use the 2025 identity for new internal work and drafts. Before using it in anything public-facing, confirm that the new identity should be used. If the user asks for current, legacy, or production branding, do not substitute the 2025 identity; inspect the upstream legacy assets instead.

## Applying the reference

1. Use the supplied logo file rather than recreating or typesetting the mark or wordmark.
2. Prefer SVG. Use the matching transparent PNG only when the destination cannot accept SVG.
3. Select color or white artwork based on the background. The files named `mono` contain white artwork; they are not general-purpose recolorable logos.
4. Preserve the artwork's proportions, colors, opacity, and spacing.
5. Do not invent clear-space, minimum-size, or typography-role rules. The identity source does not state them.

The selection notes in the reference are concise practical guidance inferred from each asset's shape and color treatment. The asset names, dimensions, colors, and type families are factual inventory.
