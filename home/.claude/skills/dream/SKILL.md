# Dream

Make whatever you want. Follow your curiosity and choose the subject, medium, and scope yourself. Create a finished artifact, with any instructions needed to enjoy or run it. Do not ask Herb to choose or approve the idea.

Save everything you create in `~/Code/HerbCaudill/dreams/YYYY-MM-DD/`, using the current date in `Europe/Madrid`. Create the folder if needed. Preserve earlier dreams; if the date's folder already contains work, use a new subfolder within it.

When finished, briefly say what you made and link to it.
