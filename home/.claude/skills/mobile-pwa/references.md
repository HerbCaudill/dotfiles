## Platform references

- [Apple's status-bar metadata](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariHTMLRef/Articles/MetaTags.html) distinguishes content below the status bar from translucent content behind it.
- [WebKit header detection](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/page/LocalFrameView.cpp) and [iOS scroll-edge handling](https://github.com/WebKit/WebKit/blob/main/Source/WebKit/UIProcess/API/ios/WKWebViewIOS.mm) were the primary-code basis of the Tasks investigation. Treat their current implementation as a heuristic.
- [Vite PWA prompt updates](https://vite-pwa-org.netlify.app/guide/prompt-for-update.html) documents the waiting-worker update flow. Version 1.3.0's installed `types/index.d.ts` and `dist/client/build/register.js` were checked for `onNeedReload` before copying the Tasks implementation.
- [MDN touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/touch-action) explains which gestures each value permits. `pan-x pan-y` permits scrolling without opting into pinch zoom; `manipulation` permits pinch zoom.
